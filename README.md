<!-- Plugin description -->
Apricode Monokai is a dark theme for IntelliJ Platform IDEs that combines the familiar Monokai structure with Apricode brand colors.

The theme includes:

- Apricode-colored editor syntax for PHP, Go, JavaScript, HTML, CSS, SQL, and other supported languages.
- Dedicated Go highlighting for declarations, calls, types, packages, constants, tags, build constraints, and variable scopes.
- Readable Git, diff, breakpoint, banner, and notification states on a dark background.
- Custom Apricode Build, Run, and Debug icons.

Marketplace automatically selects the compatible plugin release for each supported IDE version.
<!-- Plugin description end -->

## Installation

Open **Settings | Plugins | Marketplace**, search for **Apricode Monokai**, install the plugin, and restart the IDE if requested.

Select the theme under **Settings | Appearance & Behavior | Appearance**.

## Compatibility

- Apricode Monokai 2.x supports IntelliJ Platform builds `251` through `261.*`.
- Apricode Monokai 3.x supports IntelliJ Platform build `262` and newer.
